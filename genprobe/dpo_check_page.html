GenProbe — 两张图比一比 / Compare two images

开始之前 / Before you start

每题一段文字和两张图（A 在左，B 在右），题目分两部分，每题上方会写明问的是哪一个：

第一部分：哪张图更符合文字？只看物体、数量、属性、位置、动作、否定、比较、要求的文字，不看好不好看。选项：A / B / 一样 / 都不符合。

第二部分：哪张图画面更好？只看画面本身：清晰、自然、没有变形或怪异的地方、构图和光线。不看它是否符合文字。选项：A / B / 一样。

键盘：1 = A，2 = B，3 = 一样，4 = 都不符合（只在第一部分有），← → 翻题。进度自动保存在这个浏览器里；中途和最后请点右上角导出 CSV。完整说明见 docs/dpo_check_protocol.md。

Two parts: first which image matches the text better (A, B, same, neither); then which image looks better, ignoring the text (A, B, same). Keys 1-4, arrows to move; export the CSV at the end.
