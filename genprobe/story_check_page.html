GenProbe — 两段视频比一比 / Compare two videos

开始之前 / Before you start

每题一段小故事和两段视频（A 在左，B 在右）。每段视频由 3–4 个镜头接起来，会自动循环播放，可以按 R 让两段同时从头播放。题目分两部分，每题上方会写明问的是哪一个：

第一部分：哪段视频更好地讲出了这段故事？看故事里的每件事有没有发生、顺序对不对、主角和场景对不对，不看好不好看。先在心里列出每段漏掉或画错的事，漏得少、错得轻的胜出；两段一样好或一样差选“差不多”；两段都基本没讲出这个故事才选“都没讲出”。选项：A / B / 差不多 / 都没讲出。

第二部分：哪段视频里，主角从头到尾更像同一个人（或同一只动物、同一个东西）？只看主角的外貌在各镜头之间是否一致：种类、颜色、衣服、花纹等。姿势、远近、光线和角度的变化不算。不看故事讲得好不好。选项：A / B / 差不多。

键盘：1 = A，2 = B，3 = 差不多，4 = 都没讲出（只在第一部分有），R = 重播，← → 翻题。进度自动保存在这个浏览器里；中途和最后请点右上角导出 CSV。完整说明见 docs/story_check_protocol.md。

Two parts: first which video tells the brief better (A, B, same, neither); then in which video the main character stays the same from shot to shot (A, B, same). Keys 1-4, R to replay, arrows to move; export the CSV at the end.
